AirMirror 0.4.0 - Windows x64

INSTALL
1. Extract this archive to a local folder.
2. Double-click install.cmd.
3. Start "AirMirror" from the Start menu.

REQUIREMENTS
- Windows 10 or Windows 11 x64.
- PC and AirPlay receiver on the same reachable LAN.
- NVIDIA GPU plus the included FFmpeg build for 2K/4K high-refresh mirroring.
- Windows Firewall must allow AirMirror on private networks.

FILES
- airmirror-gui.exe: desktop application.
- airmirror.exe: command-line interface.
- airmirror-receiver-info.exe: receiver diagnostics.
- fpsap-helper.exe: FairPlay helper.
- ffmpeg.exe: NVENC and desktop-duplication backend.

NOTES
- Pairing does not require a PIN.
- System audio is captured through WASAPI loopback.
- User settings and credentials remain in %APPDATA%\airmirror after uninstall.
- Run uninstall.cmd to remove the application.
